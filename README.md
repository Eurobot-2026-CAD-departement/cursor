# Cursor

CAD of the **cursor mechanism** designed for Eurobot 2026, in several iterations.

## Contents
- `cursor 1.0/` — first version, as individual parts (with thicknesses in the file names, e.g. 2.7 mm / 5 mm laser-cut parts)
- `cursor 2.0/` — second iteration, including the **cursor 3.0** variants for the **yellow side** and **blue side**, vertical and horizontal **rollers**, final files, SVG files and print-ready (`impression`) files
- Logo / image files used to decorate the cursor (`harissa logo`, `harissa cursor`, ...)

---

Part of the CAD work of the **Aerobotix (INSAT, Tunisia) Eurobot 2026 team** — see the [organization](https://github.com/Eurobot-2026-CAD-departement) for the other repositories.
